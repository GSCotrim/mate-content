## Coesão sequencial: os conectivos

A **coesão sequencial** faz o texto avançar, ligando ideias por meio de **conectivos** (conjunções, advérbios, locuções). Cada conectivo sinaliza uma **relação lógica** — e trocá-lo muda o sentido.

| Relação | Conectivos típicos |
|---|---|
| Adição | e, além disso, também |
| Oposição | mas, porém, contudo, entretanto, no entanto |
| Causa | porque, já que, visto que, pois |
| Consequência | portanto, logo, por isso, assim |
| Conclusão | enfim, portanto, em suma |
| Condição | se, caso, desde que |
| Finalidade | para que, a fim de |
| Tempo | quando, enquanto, assim que |

*Exemplo original:* compare *"Estudou pouco, **mas** passou"* (oposição: surpresa) com *"Estudou pouco, **por isso** não passou"* (causa/consequência). O mesmo fato, relações opostas.

Saber a relação que cada conectivo expressa é uma das habilidades mais cobradas — e a base para reescrever períodos sem mudar o sentido.
