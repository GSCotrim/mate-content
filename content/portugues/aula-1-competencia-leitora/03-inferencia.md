## Inferência

**Inferir** é deduzir uma informação que **não está escrita**, mas que o texto permite concluir a partir de pistas e do contexto.

*Exemplo original:* a frase *"ela fechou o guarda-chuva e sacudiu o casaco molhado na entrada"* não diz que choveu — mas o leitor **infere** isso com segurança. As pistas (guarda-chuva, casaco molhado) sustentam a conclusão.

A inferência é segura quando se apoia no texto; é arriscada quando vira **adivinhação**. Compare:

| Conclusão | Tipo |
|---|---|
| "Estava chovendo." | inferência válida (há pistas) |
| "Ela estava atrasada para o trabalho." | extrapolação (sem apoio no texto) |

No ENEM, os melhores distratores são extrapolações *plausíveis*: parecem razoáveis, mas vão além do que o texto garante. Pergunte sempre: *onde, no texto, está a base para isso?*
