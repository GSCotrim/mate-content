## Para começar

**Como representar a Terra, que é uma esfera, numa folha de papel plana?**

É impossível fazer isso sem alguma distorção. Achatar uma superfície curva sempre deforma algo: as áreas, as formas, as distâncias ou as direções. Toda projeção cartográfica é, portanto, uma *escolha* — o cartógrafo decide qual erro vai tolerar para preservar aquilo que mais importa ao seu mapa.

Mapas não são fotografias neutras do mundo. São **representações construídas**, com intenções, recortes e pontos de vista. Entender como um mapa é feito é o primeiro passo para lê-lo de forma crítica — e essa leitura crítica é exatamente o que o ENEM cobra.

Nesta aula vamos ver as **projeções**, as **escalas**, os sistemas de **coordenadas geográficas**, os **fusos horários** e as tecnologias de localização como o **GPS**.
