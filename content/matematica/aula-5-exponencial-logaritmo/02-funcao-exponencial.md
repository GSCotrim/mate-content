## A função exponencial

Na **função exponencial**, a variável aparece no **expoente**:

```formula
f(x) = aˣ        (a > 0, a ≠ 1)
```

A base *a* fixa o comportamento:

- *a > 1* → função **crescente** (crescimento exponencial).
- *0 < a < 1* → função **decrescente** (decaimento exponencial).

**Características do gráfico:**

- Passa sempre por *(0, 1)*, pois *a⁰ = 1*.
- Fica sempre **acima do eixo x** (imagem só positiva): *aˣ > 0* para todo *x*.
- O eixo *x* é uma **assíntota** — a curva se aproxima dele mas nunca o toca.

```diagram
diagrama · curvas exponenciais crescente (a>1) e decrescente (0<a<1)
```

Em modelos reais usamos *f(x) = N₀ · aˣ*, onde *N₀* é a quantidade inicial. *Em juros compostos, M = C·(1 + i)ᵗ* é exatamente uma exponencial — voltaremos a ela na Aula 13.
