## Logaritmos

O **logaritmo** responde à pergunta: *"a que expoente elevar a base para obter este número?"* É a operação **inversa** da exponencial.

```formula
log_a b = x  ⟺  aˣ = b        (a > 0, a ≠ 1, b > 0)
```

*Exemplo:* *log₂ 8 = 3* porque *2³ = 8*. O **log decimal** (base 10) costuma ser escrito só como *log*.

**Propriedades operatórias (transformam produto em soma):**

```formula
log(x·y) = log x + log y        log(x/y) = log x − log y        log(xⁿ) = n·log x
```

Essas propriedades são o motivo de o logaritmo aparecer em escalas que comprimem números enormes: **pH**, **escala Richter** de terremotos e **decibéis** de som são todas logarítmicas — cada unidade representa uma multiplicação por 10.

```diagram
diagrama · escala logarítmica (Richter / decibéis) comprimindo grandes variações
```

**Atenção:** não existe logaritmo de número negativo nem de zero (*b > 0* sempre).
