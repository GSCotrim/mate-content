## Equações exponenciais

Uma **equação exponencial** tem a incógnita no expoente. A estratégia básica é **igualar as bases**: se as bases são iguais, os expoentes também são.

```formula
aˣ = aʸ  ⟹  x = y        (a > 0, a ≠ 1)
```

*Exemplo:* resolver *2ˣ = 32*. Como *32 = 2⁵*, temos *2ˣ = 2⁵*, logo *x = 5*.

O truque é reescrever os dois lados como potências da **mesma base**, usando as propriedades de potência da Aula 1.

*Exemplo:* *9ˣ = 27* → *(3²)ˣ = 3³* → *3^(2x) = 3³* → *2x = 3* → *x = 3/2*.

Quando **não** dá para igualar as bases (por exemplo *2ˣ = 10*), precisamos do **logaritmo** — a ferramenta para "descer" o expoente, que veremos a seguir.
