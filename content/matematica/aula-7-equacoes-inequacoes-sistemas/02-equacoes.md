## Equações do 1º e 2º grau

Uma **equação** é uma igualdade com incógnita; resolvê-la é achar os valores que a tornam verdadeira. O princípio: *o que se faz de um lado, faz-se do outro*.

**1º grau** — *ax + b = 0* — isola-se a incógnita:

```formula
a·x + b = 0  ⟹  x = −b/a
```

*Exemplo:* *3x − 12 = 0 → 3x = 12 → x = 4.*

**2º grau** — *ax² + bx + c = 0* — resolve-se por **Bhaskara** (Aula 4):

```formula
x = (−b ± √Δ) / (2a)        Δ = b² − 4ac
```

**Casos especiais** dispensam Bhaskara:

- *Incompleta sem c* (*ax² + bx = 0*): fator comum → *x(ax + b) = 0*, raízes *0* e *−b/a*.
- *Incompleta sem b* (*ax² + c = 0*): isola *x²* → *x = ±√(−c/a)*.
