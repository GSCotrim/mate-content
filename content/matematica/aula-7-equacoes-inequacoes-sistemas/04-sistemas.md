## Sistemas de equações

Um **sistema linear** reúne duas ou mais equações que devem ser satisfeitas **ao mesmo tempo**. A solução é o par *(x, y)* que serve para todas.

**Dois métodos clássicos para 2×2:**

- **Substituição** — isole uma incógnita numa equação e substitua na outra.
- **Adição (eliminação)** — some as equações de modo a cancelar uma das incógnitas.

```formula
{ x + y = 10
{ x − y = 2     ⟹  somando: 2x = 12 ⟹ x = 6, y = 4
```

**Interpretação geométrica:** cada equação do 1º grau é uma **reta**; a solução é o **ponto de encontro** delas.

- Retas concorrentes → **uma** solução.
- Retas paralelas → **nenhuma** solução (sistema impossível).
- Retas coincidentes → **infinitas** soluções (indeterminado).

```diagram
diagrama · duas retas cruzando-se no ponto-solução do sistema
```

Montar o sistema a partir de um enunciado (traduzir "o dobro de", "a soma é") é a habilidade mais cobrada.
