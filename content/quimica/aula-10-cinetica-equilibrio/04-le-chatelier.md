## Princípio de Le Chatelier

O **princípio de Le Chatelier** prevê o que acontece quando perturbamos um equilíbrio: *o sistema se desloca no sentido que **minimiza** a perturbação*.

Três perturbações principais:

- **Concentração** — adicionar um reagente desloca para os **produtos** (e vice-versa); remover um produto também puxa para os produtos.
- **Pressão (gases)** — aumentar a pressão desloca para o lado de **menor número de mols** gasosos; diminuir, para o de maior número. (Não afeta equilíbrios sem variação de mols gasosos.)
- **Temperatura** — aumentar favorece o sentido **endotérmico**; diminuir favorece o **exotérmico**. **Só a temperatura altera o valor de Kc**.

**Importante:** o **catalisador não desloca** o equilíbrio — ele apenas faz o sistema **atingir** o equilíbrio mais rápido.

Aplicação clássica: o **processo Haber** (síntese de amônia, `N₂ + 3 H₂ ⇌ 2 NH₃`) usa **alta pressão** (desloca para o lado de menos mols, a amônia) para aumentar o rendimento — um exemplo direto de Le Chatelier na indústria.
