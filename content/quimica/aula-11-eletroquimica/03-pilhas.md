## Pilhas

Uma **pilha** (célula galvânica) converte energia **química em elétrica** por meio de uma oxirredução **espontânea**. A clássica é a **pilha de Daniell** (zinco e cobre).

Componentes e regras:

- **Ânodo** — eletrodo onde ocorre a **oxidação**; é o polo **negativo**. No Daniell, é o **zinco** (Zn → Zn²⁺ + 2 e⁻), que se **corrói**.
- **Cátodo** — eletrodo onde ocorre a **redução**; é o polo **positivo**. No Daniell, é o **cobre** (Cu²⁺ + 2 e⁻ → Cu), que **aumenta** de massa.
- Os **elétrons fluem pelo fio externo** do ânodo para o cátodo.
- A **ponte salina** mantém a neutralidade elétrica das soluções.

```formula
Zn  +  Cu²⁺  →  Zn²⁺  +  Cu          (reação global do Daniell)
```


O **potencial-padrão de redução (E°)** mede a tendência de uma espécie em **se reduzir**. Quem tem maior E° **se reduz** (cátodo); quem tem menor E° **se oxida** (ânodo). A diferença dá a voltagem da pilha:

```formula
ΔE° = E°(cátodo) − E°(ânodo)
```

Se **ΔE° > 0**, a reação é **espontânea** — a pilha funciona. (Os valores de E° são fornecidos na prova; o que se cobra é o raciocínio.)
